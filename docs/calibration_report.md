## E6.2 — Калібрування на польових даних (2026-10-04)

Глобальні константи: `TARTRATE_L = 7` г/л (Kliewer 1971: тартрат дозрілої ягоди 4–7 г/л), `K_MAL = 0.08` доб⁻¹@20°C → TA(blanc) = 7 г/л; MALATE_L = 12 без змін.
pH — емпіричний агрегат (основа 3.05 + K⁺-терм): калібрований pH(blanc) = 3.08, у межах ТЗ 3.0–3.6; точніше калібрування потребує польових даних K⁺ ягоди.
Цілі: ТЗ §8 (Brix 18–24, TA 4–9 г/л, pH 3.0–3.6) + сортові дані E6.1.
