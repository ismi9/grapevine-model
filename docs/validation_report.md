# Звіт валідації — ворота G3 та G5
Дата: 2026-10-04 · Автотест: `validation/mass_balance.js` (28/28 PASS)

## 1. Масовий баланс (принцип §2 ТЗ)
Точність леджера C, N, ґрунтових пулів на 11 сценаріях (Tier 1 і Tier 2,
усі форми N, суша, спека, холод): фактична нев'язка ≤ 1e-15 відносної
(допуск ТЗ ≤ 1e-6). Баланс досягнуто через exact-леджер потоків (рішення D-007):
усі переходи пулів ідуть через явні потоки; «голодання» реалізовано як
пригнічення дихання доступним C, а не як кламп.

## 2. Граничні умови (red team)
• Майже повна темрява (2 % PAR): ріст лише за рахунок весняних резервів.
• Крайня суша: LAI < 1.0, врожай скорочується на ~33 % (ягоди дрібніші — Локгарт).
• Дефіцит Mg: фотосинтез падає майже до нуля (хлороз-проксі).

## 3. Напрямки ефектів (ворота G5, §3.5 ТЗ)
Усі 9 напрямків збігаються з таблицею ТЗ:
надлишок N ↓ терпени; дефіцит N ↓ YAN/LAI; помірний водний дефіцит ↑ терпени;
експозиція грона світлу ↑; затінення ↓; перевантаження → розбавлення + затримка;
низьке навантаження ↑ концентрація; спека → раніший збір; холод → не дозріває.

## 4. Правдоподібність (§8 ТЗ)
Brix 20.6 (ціль 18–24) · TA 9.2 (4–9.5) · pH 2.97 (2.85–3.6) ·
LAI 3.0 (1.5–3.5) · ягода мускату білого 1.3 г (1–2) · врожай 8.2 т/га.

## Обмеження звіту (чесно)
• Валідація якісна (напрямки/діапазони), не кількісна на польових даних —
  калібрування на незалежних сезонах залишено на E6.
• Пороги одоряції та сортові профілі терпенів — ASSUMPTION, потребують E1-огляду.
• Статистичні метрики (RMSE/NSE/bias/R²) з'являться після E6 з польовими даними.
