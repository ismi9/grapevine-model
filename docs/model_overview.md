# Огляд моделі Tier 1 — «VineSeason»

## Що це
Балансова модель повного сезону вегетації виноградного куша (Vitis vinifera L.)
з акцентом на формування якості мускатних сортів (монотерпеноли: вільні + глікозидно-зв'язані).
Реалізована як чистий JS-модуль (app/js/model.js) для запуску в браузері без сервера.

## Стани (пули)
- **Органи** (г сухої маси на куш): листя, молоді пагони, коріння, грона/ягоди.
- **Вуглець**: асиміляція (GPP) → дихання підтримки (Q10) + вартість росту →
  алокація за фенологічною фазою (sink-priority) → резерви (крохмаль деревини/коріння).
- **Азот**: ґрунтовий пул (мінеральний N, кг/га) → поглинання (Міхаеліс–Ментен, T- і волого-залежне) →
  алокація в органи за цільовими концентраціями → ремобілізація при листопаді.
- **Ягода**: подвійна сигмоїда (фаза I 65 % маси → лаг → фаза III), цукор (Brix),
  малат (накопичення до véraison → дихання після), тартрат (раннє накопичення → розбавлення),
  pH (агрегат Henderson–Hasselbalch з K⁺).
- **Терпеноїди**: синтез (проксі MEP-шлях, сорт-залежний) → глікозилювання (T-залежна ензиматика) →
  втрати (окиснення/випаровування; різкі при T > 32–35 °C).

## Керовані входи
Сорт (4 мускатні профілі) · сценарій погоди (холодний/типовий/спекотний) + зсув ΔT ·
PAR · вода (з помірним дефіцитом після зав'язування) · N-добриво (кг/га, три BBCH-вікна внесення) ·
P, K, Mg, B, Zn (функції обмеження за Лібіхом) · навантаження (бруньки/куш) ·
видалення листя й експозиція грона.

## Відповіді моделі (калібрувальні цілі, розділ 8 ТЗ)
| Показник | Правдоподібний діапазон |
|---|---|
| LAI повний розвиток | 1.5–3.5 |
| Чистий фотосинтез (порядок) | 10–20 мкмоль CO₂·м⁻²·с⁻¹ |
| Brix збору мускатів | 18–24 °Bx |
| TA дозрівання | 4–9 г/л · pH 3.0–3.6 |
| Ягода мускату білого | 1–2 г |
| Вільні монотерпеноли мускату | ~400–1600 мкг/кг (верифікувати) |

## Якісні відповіді, які модель відтворює (перевірено сценаріями)
- Надлишок N ↑ вегетативна маса, ↓ терпеноїди (затінення, конкуренція за C).
- Дефіцит Mg ↓ фотосинтез; дефіцит води ↓ ріст; помірний дефіцит після зав'язування ↑ концентрація терпенів.
- Спека > 35 °C ↓ синтез терпенів, ↑ втрати; холодний сезон — врожай не дозріває.
- Перевантаження врожаєм → ↓ Brix, затримка дозрівання; низьке навантаження → раніший збір, ↑ ароматика.

## Межі застосування (чесно)
- Tier 1: немає окремої FvCB-кінетики (Vcmax/Jmax), немає фотодихання і продихової провідності —
  вони агреговані у добову ефективність ε₀ з дзвоноподібною температурною кривою.
- Немає багаторічного режиму (резерви на наступний сезон не переноситься).
- Ґрунтова хімія спрощена до одного мінерального N-пулу (нітрифікація/денітрифікація агреговані).
- Фенологія — GDD-пороги, не модель Chuine; пороги калібрувальні.
- Параметри терпенів — калібрувальні проксі (VvDXS1-активність), потребують валідації на польових даних.
- Результати ілюстративні і не є агрономічною рекомендацією.

## Наступні етапи (за ТЗ)
E5: Tier 2 — кінетика Міхаеліса–Ментен/Арреніус, окремі NO₃⁻/NH₄⁺, MEP/MVA-мережа, стильбени/флавоноли.
E6: калібрування (Morris → Sobol, ансамблі) на польових даних; чесні довірчі інтервали.

## Додаток: Tier 2 (етап E5)

### Фотосинтез (Блок A, Tier 2)
FvCB-агрегат по 5 шарах крони з градієнтом PAR (екстинкція k=0.7):
Vcmax25 = 70 × (N_листя/оптимум)^0.7 × f(Mg) × f(P) — зв'язок N→Rubisco→Vcmax;
Jmax25 = 1.67×Vcmax25; температурна крива fV(T): активація Ha=50 кДж/моль +
дезактивація >34 °C [ASSUMPTION — точно відтворені літературні константи
Bernacchi/Kattge-Knorr визнано неперевіреними, D-006]; ci = 0.7×ca×f(вода) —
продихи закриваються при стресі. A_шару = min(Ac, Aj).

### Азот (Блок C, Tier 2)
Ґрунт: три пули (NO₃⁻, NH₄⁺, сечовина). Гідроліз сечовини (уреаза, T-залежний),
нітрифікація NH₄⁺→NO₃⁻, вимивання (NO₃⁻ сильніше), денітрифікація.
Поглинання: окремі Міхаеліс–Ментен для NO₃⁻ (Vmax 0.12, Km 0.05) і NH₄⁺
(0.08, 0.02 г N/добу). Внутрішні пули: нітратний запас (кап 1.2 г N),
амінний пул; відновлення NO₃⁻ коштує 0.6 г C/г N і лімітоване доступним C —
при бідному вуглецевому статусі нітрат накопичується (реальна фізіологія).
Надлишок → «розкішне» накопичення в листі → зниження терпенів і ↑ вегетація.

### Терпеноїди (розділ 3.5, Tier 2)
Мережа MEP-проксі: синтез (сортовий DXS × фактори) розподіляється на 5 сполук
сортовими профілями синтаз (ліналоол, гераніол, нерол, α-терпінеол, цитронелол);
ліналоол окиснюється → оксиди ліналоолу (хімічне, швидше при спеки);
глікозилювання окремими к-стями (гераніол найшвидший — консистентно з VvGT14);
втрати окиснення/випаровування T-залежні.
Вихід: по сполуках вільні/зв'язані (мкг/кг), співвідношення ліналоол/гераніол,
OAV-зважений індекс мускатності (пороги одоряції — ASSUMPTION).

### Ріст ягоди (Блок F/G, Tier 2)
Фази I/III масштабуються забезпеченістю водою (модель Локгарта, спрощено):
тургор обмежує розширення клітин; водний стрес → дрібніші ягоди.

### Валідація (ворота G5)
validation/mass_balance.js — 28 автотестів: масовий баланс (≤1e-6, факт ≤1e-15),
граничні умови, 9 напрямків ефектів за §3.5, правдоподібність за §8.
Прогін: `node validation/mass_balance.js` (також у CI).
